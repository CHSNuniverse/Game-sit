# 州际独立战争模拟器（美国）

一个网页版原型：将美国按州拆分，基于可调参数（军事、经济、产业、文化、人种紧张度、战术）进行实时战争演化，观察哪一州最终统一。

## 快速开始

直接在浏览器打开 `index.html` 即可。

> 说明：地图数据通过 CDN 加载 `us-atlas`，需要联网。

## 已实现能力

- 美国州地图可视化（SVG）。
- 各州初始属性自动生成，可点击州进行手动调整。
- 战术风格切换：闪击、经济封锁、纵深防御、渗透叛乱。
- 实时 Tick 模拟、暂停/重置。
- 战争倍率（速度）与战争烈度调节。
- 地图实时变色反映控制权变化。
- 统一进度榜和战报日志。

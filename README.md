# 州际独立战争模拟器（美国）

一个网页版原型：将美国按州拆分，基于可调参数（军事、经济、产业、文化、人种紧张度、战术、兵种）进行实时战争演化，观察哪一州最终统一。

## 快速开始

直接双击打开 `index.html` 即可运行（本版本不依赖网络/CDN）。

## 已实现能力

- 美国 50 州策略网格地图（州缩写 + 州名标注，可点击州块编辑参数）。
- 各州参数可编辑：军事、经济、产业、文化、人种、陆军、空军、海军、战术风格。
- 多方向蚕食占领：同一州可从左/右/上/下多个战线同步推进，不再单方向换色。
- 外交系统：支持结盟、停战、背刺；外交关系实时影响是否可开战与联盟战力。
- 兵种系统：陆军/空军/海军影响总体战力，并影响占领推进速度（海军对沿海州有额外效果）。
- 实时 Tick 模拟、暂停/重置、战争倍率与烈度调节。
- 统一进度榜、外交关系面板、战报日志。
- 预设场景（均衡/军工/经济/文化撕裂）、配置导出与 JSON 导入。

## 为什么之前打不开

上一版依赖外部 CDN 与远程地图数据，请求在部分本地环境会被拦截（尤其是直接 `file://` 打开 HTML 时）。
现在改成纯本地数据与本地脚本，避免这类加载失败。

## 提交冲突排查（Git）

如果你本地提交/合并时频繁冲突：

1. 先执行 `git status` 查看是否有未完成合并。
2. 执行 `git merge --abort`（若处于 merge 状态）或 `git rebase --abort`（若处于 rebase 状态）。
3. 重新拉取远端后再合并：`git fetch origin && git rebase origin/main`。
4. 本仓库已添加 `.gitattributes`，统一为 LF 换行，减少跨平台冲突。

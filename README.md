## 已实现能力

- 美国州地图可视化（SVG）。
- 各州初始属性自动生成，可点击州进行手动调整。
- 战术风格切换：闪击、经济封锁、纵深防御、渗透叛乱。
- 实时 Tick 模拟、暂停/重置。
- 战争倍率（速度）与战争烈度调节。
- 地图实时变色反映控制权变化。
- 统一进度榜和战报日志。

现在改成纯本地数据与本地脚本，避免这类加载失败。
